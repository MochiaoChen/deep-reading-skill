# 读书笔记评分标准

四个要素，每项 0–3 分，满分 12。**10 分以下就还没研读完。**

打分时只指出**最短的那块板**，给一条修改建议。别列十条——列十条等于没建议。

---

## ① 逻辑脉络（Logic）

> 每一章作者到底想说什么，各章如何串成系统。

| 分 | 标准 |
|---|---|
| 0 | 没有脉络，只有摘抄或金句 |
| 1 | 有「中心思想 + 段落大意」式的概括，但是抄的原句 |
| 2 | 用自己的话写了每章要点，但看不出章与章之间怎么串 |
| 3 | 用自己的话写出脉络，且串起来能看出全书的系统 |

**这一项是及格线。** 大多数人之所以没真正理解一本书，就是因为看不见这个脉络。

**反例（1 分）**
> 第三章讲了市场的作用。作者认为市场是有效的，同时也会失灵。

——这是段落大意。它没告诉你作者**为什么**要在第三章讲市场，也没告诉你它和第二章的关系。

**正例（3 分）**
> 【第 1–2 章立了「稀缺」这根柱子：没稀缺赚不到钱，有稀缺也得靠区别定价才赚得到。第 3–5 章是这根柱子的推论——经济学家喜欢市场，是因为市场能自动消解稀缺；反过来，某些以公平为名的政策（比如不让优质小学入学市场化）客观上是在制造稀缺。所以第 6 章说亚马逊没有真正的稀缺力量，是在给前五章做一个反面校验。】

**自检问句**：把各章脉络单独抽出来连读，能看出这是一本书而不是十篇文章吗？

---

## ② 亮点（Highlights）

> 拍案叫绝的、一语惊醒梦中人的东西，连细节一起带走。

| 分 | 标准 |
|---|---|
| 0 | 没有亮点，或亮点全是段落首句/末句这类「总结句」 |
| 1 | 有摘抄，但被缩写成了梗概，细节丢了 |
| 2 | 有几条保留细节的亮点，但每章都摊了一两条，很均匀 |
| 3 | 亮点分布**不均匀**，且保留了足以复用的细节 |

**均匀就是错的。** 有的章值三条，有的章一条都不值。每章都恰好两条，说明你在交作业。

**反例（0 分）**
Kindle 上大多数人划的重点是段落的第一句或最后一句——那是小学生找中心句的线性读法。

**正例（3 分）**
真正的读法是「一惊一乍」的：哪句话令人拍案叫绝？哪句话一语惊醒梦中人？把**那样的**东西突出记下来。

**自检问句**：三年后要写一篇文章，从这份笔记里能直接抠出可用的素材吗？

## ③ 心得（Commentary）

> 自己的看法、质疑、灵感。**必须来自读者本人。**

| 分 | 标准 |
|---|---|
| 0 | 全是书里的话，一句自己的都没有 |
| 1 | 有几句「很有启发」「值得深思」式的空话 |
| 2 | 有具体的赞同或质疑，但都在书的射程之内 |
| 3 | 有书本身没讨论的东西：反例、外推、或解决了自己原有的某个不相干的问题 |

**约定**：自己的话一律放进 `【】`。

**这一项决定笔记的长期价值。** 多年后翻笔记，往往是心得比原书更有价值。

**空话 vs 心得**

| 1 分 | 3 分 |
|---|---|
| 【很有道理，值得深思。】 | 【这个结论假定了信息是对称的。我们公司去年那次定价失败恰好是反例——顾客能查到批发价，区别定价就崩了。】 |
| 【作者说得对。】 | 【如果把这个逻辑往前推一步，那么「免费」不是没有稀缺，而是稀缺转移到了注意力上。这正好解释了我一直没想通的那个问题。】 |

**自检问句**：这一栏里有没有一句话是作者不可能写出来的？

## ④ 联系（Links）

> 这个问题别的书怎么说？

| 分 | 标准 |
|---|---|
| 0 | 一本书自成孤岛，没有任何外链 |
| 1 | 提了「这让我想起某本书」，但没说哪里像 |
| 2 | 指出了与其他书的**共同点** |
| 3 | 指出了**不同点**，并判断了谁的证据更强 / 结论是否被更新 |

**共同点容易找，不同点才值钱。** 有没有更新的证据支持或反对这个结论？

**正例（3 分）**
> 【与 [[思考快与慢]] 第 2 部分冲突。卡尼曼认为这类判断偏差是系统性的、几乎不可训练的；本书作者却默认从业者能通过经验校正。我倾向卡尼曼——他有实验，本书只有案例。】

**升级信号**：如果同一个问题你在三本以上的书里读到过不同结论，并且你能判断高下——你已经和作者平等了，该写文章了。

## 综合诊断速查

| 症状 | 缺哪一项 | 一句话诊断 |
|---|---|---|
| 只有摘要概括 | ① | 看不出脉络，等于没读懂 |
| 通篇金句摘抄 | ① | 记住了树木，忘了森林 |
| 每章字数差不多 | ② | 这是交作业，不是记笔记 |
| 全是书里的话 | ③ | 你只是个复读机 |
| 一本书自成孤岛 | ④ | 知识没有进网络 |
| 只记到全书四分之一 | 全部 | 你和 Kindle 上的大多数人一样 |
| 记住了「咖啡」没记住「稀缺」 | ① | 把例子当成了主题 |
